# GeoPin Route Studio

A lightweight browser-based GIS utility for plotting latitude/longitude waypoints on an interactive SVG canvas, calculating Haversine leg distances, and exporting standard GeoJSON files.

## Features
- **Haversine Distance Engine**: Accurate great-circle distance calculation per leg in km and miles.
- **SVG Coordinate Plotter**: Instant route visualization with bounding-box telemetry.
- **GeoJSON Export**: One-click export compatible with QGIS, Mapbox, and GitHub's native GeoJSON map renderer.

## Quick Start
Open `index.html` in any browser.
